# Sky Bot SDK

Ставится **на ваш сервер**. Код бота выполняется там же, где стоит эта
программа, — на сервере Sky он не выполняется никогда.

```
   ВАШ СЕРВЕР                         SKY
  ┌──────────────┐                ┌──────────────┐
  │  bot.js      │                │  Bot API     │
  │  Sky Bot SDK │ ──события───→  │  очередь     │
  │  (этот пакет)│ ←──действия──  │  чаты, люди  │
  └──────────────┘                └──────────────┘
   ваш процессор                   база и связь
   ваша память
```

Sky не подключается к вашей оболочке, не запускает ваш `bot.js`, не
поднимает контейнер и не держит ваш процесс. Он складывает события и
принимает действия — и всё.

## Что нужно

Node 18 или новее. Внешних зависимостей нет.

## Запуск за пять минут

**1. Заведите бота.** Sky → вкладка «Sky» → «Мои боты» → «Создать».

**2. Получите код привязки.** В карточке бота — «Подключить сервер».
Код одноразовый и живёт 10 минут.

**3. Поставьте SDK на свой сервер.**

```bash
mkdir мой-бот && cd мой-бот
npm init -y && npm pkg set type=module
npm install sky-bot-sdk
```

**4. Напишите бота** — `bot.mjs`:

```js
import { SkyBot } from 'sky-bot-sdk';

const bot = new SkyBot({ label: 'мой сервер' });

bot.on('start',   () => 'Привет! Я живу на сервере своего владельца.');
bot.on('message', ({ command, args, text }) => {
  if (command === '/echo') return args;
  if (command === '/help') return '/echo <текст>';
  return `Вы написали: ${text}`;
});

bot.start();
```

**5. Запустите — первый раз с кодом:**

```bash
SKY_BOT_API=https://ваш-sky/api/bots/rt \
SKY_BOT_PAIRING_CODE=SKY-XXXX-XXXX \
node bot.mjs
```

Дальше код не нужен: учётные данные лежат в `.sky-bot.json` рядом.

```bash
SKY_BOT_API=https://ваш-sky/api/bots/rt node bot.mjs
```

В «Моих ботах» бот станет зелёным. Выключите процесс — станет серым,
и Sky напишет собеседникам честное «бот офлайн», а не будет делать
вид, что он на связи.

## Настройки

| Переменная | Что это |
|---|---|
| `SKY_BOT_API` | адрес Bot API, например `https://ваш-sky/api/bots/rt` |
| `SKY_BOT_PAIRING_CODE` | код привязки. Нужен только при первом запуске |
| `SKY_BOT_STATE` | где хранить учётные данные (по умолчанию `./.sky-bot.json`) |
| `SKY_BOT_LABEL` | как назвать этот сервер в списке владельца |

Те же значения можно передать в конструктор: `new SkyBot({ api, pairingCode, stateFile, label })`.

## Файл `.sky-bot.json`

В нём лежит секрет вашего сервера. Он создаётся с правами `0600`.

* **не кладите его в git** — добавьте в `.gitignore`;
* потеряли — не страшно: в «Моих ботах» нажмите «Перепривязать»
  и запустите с новым кодом. Старые учётные данные перестанут
  работать в ту же секунду.

## События

| Событие | Когда | Что в `data` |
|---|---|---|
| `start` | человек открыл диалог с ботом | `chatId`, `userId` |
| `message` | сообщение в чате, где есть бот | `chatId`, `messageId`, `from {id,name}`, `text`, `command`, `args` |
| `inline_query` | человек набрал `#триггер …` в чате | `queryId`, `chatId`, `from`, `query` |

Обработчик может вернуть строку — она уйдёт ответом в тот же чат.
Может ничего не вернуть — бот промолчит. Может позвать `api.send()`
сколько угодно раз.

Если обработчик упал, событие **не подтверждается** и Sky выдаст его
снова через минуту. Потерять сообщение из-за ошибки в коде нельзя.

## Inline-боты

Inline — это когда человек вызывает бота прямо в поле ввода чужого
чата. Важное отличие от обычного сообщения: **бот не пишет за
человека**. Он предлагает варианты, человек выбирает и подтверждает,
и только тогда сообщение уходит — от его имени.

```js
bot.on('inline_query', ({ query, from }) => [
  { title: 'Сказать', text: `${from.name}: ${query}` },
  { title: 'Громко',  text: `${from.name}: ${query.toUpperCase()}` },
]);
```

Что вернуть — список из `{ title, text }`, не больше восьми. Вариант
живёт две минуты; не подтвердили — пропал.

Чтобы триггер заработал, включите inline в карточке бота и опубликуйте
его: черновики по `#` не вызываются.

## Вебхук вместо опроса

По умолчанию SDK сам приходит за событиями и висит на длинном запросе.
Это работает за NAT, за домашним роутером, в контейнере без входящего
порта — то есть почти везде, и ничего настраивать не нужно.

Если у вас уже есть веб-сервер с белым адресом и https, можно
переключиться на вебхук: «Мои боты» → бот → «Доставка» → «Вебхук».
Sky будет стучаться к вам сам.

Тогда **обязательно** проверяйте подпись:

```js
import { verifyWebhook } from 'sky-bot-sdk';

app.post('/sky-hook', express.raw({ type: 'application/json' }), (req, res) => {
  const ok = verifyWebhook({
    secret:     process.env.SKY_WEBHOOK_SECRET,
    deliveryId: req.get('X-Sky-Delivery'),
    timestamp:  req.get('X-Sky-Timestamp'),
    signature:  req.get('X-Sky-Signature'),
    body:       req.body.toString('utf8'),
  });
  if (!ok) return res.sendStatus(401);

  const { events } = JSON.parse(req.body.toString('utf8'));
  // …обработать…
  res.sendStatus(200);   // 2xx = доставлено, событие гасится
});
```

`verifyWebhook` проверяет три вещи, и все три обязательны: подпись
(иначе запрос подделает кто угодно), время (иначе перехваченный запрос
повторяют вечно) и номер доставки (иначе его повторят и бот обработает
дважды).

Тело подписи — **сырые байты**, а не разобранный JSON: `express.json()`
переставит ключи, и подпись не сойдётся. Отвечайте 2xx только после
того, как событие обработано: на 4xx и 5xx Sky повторит доставку.

## Bot API

Всё, что SDK делает под капотом, — обычный HTTP. Если Node вам не
подходит, повторите то же самое на чём угодно.

| Метод | Путь | Зачем |
|---|---|---|
| POST | `/pair` | обменять код привязки на учётные данные. **Один раз** |
| POST | `/session` | обменять учётные данные на токен (час) |
| GET | `/me` | кто я, в каких чатах состою |
| GET | `/events?wait=25000` | получить события; ждёт до 25 с |
| POST | `/ack` | подтвердить обработку: `{ ids: [...] }` |
| POST | `/send` | написать в чат: `{ chatId, text }` |
| POST | `/inline/answer` | ответить на inline: `{ queryId, results }` |
| POST | `/error` | рассказать о своей ошибке владельцу |
| POST | `/heartbeat` | отметиться живым (нужно только при вебхуке) |

Все, кроме `/pair` и `/session`, — с `Authorization: Bearer <токен>`.

Чего в Bot API **нет и не будет**: кошелька, Sky ID, чужих ботов,
админских ручек. Идентификатор вашего бота Sky берёт из токена, а не из
тела запроса, — прислать чужой бесполезно.

## Что бывает не так

**`invalid_code` при привязке.** Код одноразовый и живёт 10 минут.
Использованный второй раз не подойдёт — выпустите новый.

**`unauthorized` в работе.** Сервер отвязали в «Моих ботах» или
перепривязали к другой машине. Удалите `.sky-bot.json` и привяжите
заново.

**Бот зелёный, но молчит.** Посмотрите «Логи» в карточке бота: там
видно, приходят ли события и не падает ли обработчик.

**«Очередь заполнена».** Сервер давно не забирал события. Поднимите
его — накопленное придёт сразу; всё, что старше суток, Sky выбрасывает.
