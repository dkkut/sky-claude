# Аудит Sky — отчёт (2026-11)

Договорённости: критичное сначала, инфраструктура — только конфигурация репозитория, зависимости — только патчи, миграции — только добавляющие, **код работающих сервисов не удалялся** (подробности — `CLEANUP_REPORT.md`). Подробности по безопасности — `SECURITY_REPORT.md`, по деньгам — `FINANCIAL_SECURITY_REPORT.md`, ход работ — `AUDIT_PROGRESS.md`.

## Архитектура (кратко)
- Клиент: React 18 + Zustand + Vite (`src/`), оболочки по устройствам (веб/ПК, телефон, TV, Car, Console, Speaker); приложения Android (Capacitor) и Windows (Electron) носят интерфейс внутри себя.
- Сервер: Node ESM (`server/*.mjs`, 242 файла; 88 файлов маршрутов в `server/routes/`), PostgreSQL (162 миграции), Redis (сессии, лимиты), WebSocket-хаб (`signal.mjs`), nginx, certbot; Docker Compose. Наружу — только 80/443.
- Деньги: `wallet.mjs` (кошелёк, баллы, журнал), SkyKassa (пополнение), Sky Codes (промокоды и кампании), подписки Prime/GO/Market.
- Доступ: Sky ID → профили; права сотрудников по ролям; двухэтапный вход в админку; владелец с подтверждением критических операций.
- Хранилище: шифрованные медиа на диске/S3, резервные копии SBK1, БД-вложения мессенджера.

## Что проверено в этом аудите
Статический обход: маршруты без проверки сессии/прав, запись баланса и подписок мимо сервисов, склейки SQL, исходящие запросы (SSRF), `innerHTML`/`eval`/`child_process`, секреты и заглушки, Docker Compose и заголовки nginx, `npm audit`. Динамически: обход 94 админских адресов (940 проверок), тесты новых правок, регрессия 14 существующих наборов (результаты — `AUDIT_PROGRESS.md`).

## Баги (кроме безопасности)
В ходе аудита найдено и исправлено: ошибка типа записи при обмене рублей на баллы (рубли ушли без записи — F4); бессрочный Prime при покупке (F2). Вычитывание всей кодовой базы на логические ошибки не проводилось — опирались на существующие тесты модулей.

## Не проверено
Боевой сервер и его ОС/firewall/SSH/TLS; восстановление из резервной копии; нагрузка; реальные платёжные провайдеры, почта, СМС; Android/Windows в бою; построчный аудит модулей Market, GO, Blox, Garant, мессенджера и звонков; автоматический перебор IDOR по всем пользовательским адресам.

## Остаточные риски
S4–S7 выше; блокировка входа по почте позволяет злоумышленнику временно запирать чужой вход (письмо владельцу приходит); пределы запросов хранятся в памяти процесса (при нескольких экземплярах API считаются раздельно — сейчас экземпляр один); сверка баланса не охватывает старые записи без валюты. **Нельзя утверждать, что система «полностью защищена»**: аудит закрыл найденное, но охватил не всё (см. «Не проверено»).
