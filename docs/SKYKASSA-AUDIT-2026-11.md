# Аудит SkyKassa и кошелька (ноябрь-2026)

Аудит сделан по коду перед добавлением переводов по Sky ID. Это внутренний документ.

## Что есть
- **Балансы.** `wallet_accounts`: рубли (`balance`) и баллы Prime Points (`points`) — отдельные поля, не смешиваются. Валютные счета (USD, EUR, GBP, CNY, KZT, TRY) — `wallet_fx_accounts`, только в сотых долях валюты, открываются человеком (до 5).
- **История.** `wallet_transactions` (журнал только дописывается, триггер `wallet_ledger_guard`; поле `currency` = `rub`/`pts`), обмены валют — `wallet_fx_transfers` (с курсом на момент операции), пополнения — `skykassa_payments` со статусами.
- **Провайдеры.** Реальных платёжных провайдеров нет. Есть адаптер `hmac-v1` для партнёров (`skykassapartners.mjs`) и ручной путь: человек переводит по реквизитам, сотрудник проверяет, владелец подтверждает кодом.
- **Комиссии.** За пополнение комиссии нет; бонус за первое пополнение (баллы); комиссия Blox — только в баллах и только внутри Blox.
- **Пополнение.** Только рубли. Зачисление — одной транзакцией под `FOR UPDATE` платежа, `skykassa_credits.payment_id` — первичный ключ (двойное зачисление невозможно).
- **Списание.** `wallet.spendIn/spend`; детские профили — с лимитами; идемпотентность — у конкретных сценариев (покупки, обмен).
- **Возвраты.** Для SkyKassa — запись `skykassa_refund`; решает сотрудник/владелец; автоматических возвратов нет.
- **Подтверждение операций.** Пополнения — человек → сотрудник → владелец с кодом; настройки — код `skykassa_settings`; курсы валют — владелец + код `fx_rates`.

## Чего не было (и что сделано)
| Пробел | Сделано |
|---|---|
| Перевода между людьми не было вовсе | `walletp2p.mjs`: поиск по @нику → сведения о получателе → котировка (комиссия, итог, подписанный токен) → подтверждение → серверная перепроверка → одна транзакция |
| История валют была разрозненной | `GET /api/wallet/history?currency=` — рубли, обмены и переводы, у каждой записи валюта, комиссия, курс на момент операции |
| Комиссии за переводы нет | Настраивается владельцем (по умолчанию 0), показывается до подтверждения, хранится отдельно от суммы |
| Подготовки к иностранным провайдерам нет | Учёт заявок и чек-лист допуска (`skykassa_intl_providers`); ничего не подключает |

## Что осталось как есть (честно)
- Пополнение в иностранной валюте невозможно, пока нет настоящего провайдера, договора и адаптера: валютные счета пополняются только обменом из рублей.
- Курс валют — официальный курс ЦБ (или вручную), а не рыночная котировка.
- Лимиты и метки подозрительного — эвристики, не антифрод-система; блокируются только превышения лимитов.
- Вывод денег из Sky переводами не создаётся: перевод идёт между кошельками Sky.
