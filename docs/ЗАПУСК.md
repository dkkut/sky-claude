# 🚀 Как запустить SKY локально

## Шаг 1 — Распаковать архив
Распакуй SKY_V5.1.0-beta.zip в любую папку, например `C:\sky` или `~/sky`

## Шаг 2 — Установить Node.js (если не установлен)
Скачай с https://nodejs.org — версия 18 или выше (LTS)
Проверь: `node -v` → должно показать v18+

## Шаг 3 — Установить зависимости
Открой терминал в папке sky_work и запусти:
```
npm install
```
Это займёт 1-2 минуты (скачивает пакеты).

## Шаг 4 — Запустить
```
npm run dev
```
или напрямую:
```
npx vite --host 0.0.0.0 --port 4173
```

## Шаг 5 — Открыть браузер
http://localhost:4173

---

## Войти как admin (Kutuzov)
- Телефон: `+79000000000`
- Код: `0000`

---

## Если порт занят
Поменяй порт в команде:
```
npx vite --port 3000
```
Затем открой http://localhost:3000

---

## Возможные ошибки

### "Cannot find module" или белый экран
→ Убедись что npm install прошёл без ошибок

### Порт 4173 занят
→ Запусти на другом: `npx vite --port 3001`

### Ошибки TypeScript при сборке
→ Для dev-режима они не критичны, всё равно работает
