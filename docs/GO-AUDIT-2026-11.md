## Проблемы по приоритетам

**Критические:** не найдено при чтении кода (идемпотентность, `FOR UPDATE`, цена только с сервера, коды хешируются). Проверка изоляции — в тестах (`go-test` 231, `go-biz-test` 168).

**Высокие**
1. Цена не фиксируется между расчётом и заказом: тариф можно изменить между экранами — пассажир подтвердил одно, заказ создан по другому. → `gopricing.mjs`: котировка с версией тарифа, сроком, подписью; `price_changed` с новой котировкой.
2. Нет предложений водителям: все видят все заказы города, нет тайм-аута, очерёдности и справедливости; «потерявший связь» водитель остаётся кандидатом. → `godispatch.mjs`.
3. Переходы статусов размазаны по модулям; единой таблицы нет. → `gostate.mjs` (проверка в `setStatus`).
4. Нет сквозной защиты от вечного «поиска»: заказ без водителя висит. → тайм-аут поиска.

**Средние:** диспетчерский экран и метрики распределения; ручное назначение; история уведомлений/настройки получателя; единый центр обращений Sky GO; тарифные изменения не пишут версию; дублирование проверок `canAccept` между такси и доставкой.

**Низкие:** дизайн-система Sky GO — общие кирпичи уже есть (`ui.tsx`), но не все экраны на них; пакетная загрузка заказов бизнеса отсутствует (нужна серверная валидация — не делалась).
