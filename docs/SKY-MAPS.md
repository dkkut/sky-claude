# Sky Maps — аудит и план (ноябрь 2026)

Что было до работы: `server/maps.mjs` — единый вход для карт (геокодер, картинка, маршрут Google), Яндекс подключён вторым поставщиком
(Static API + HTTP Геокодер, ключи `YANDEX_MAPS_KEY`/`YANDEX_GEOCODER_KEY`), клиентский `SkyMap` (картинка с сервера, подписи поверх) используется в Sky GO,
логистике, ПВЗ, Market, парковках. Карты рисуются **картинкой с нашего сервера**: политика безопасности (CSP) не пускает чужие скрипты, ключ в браузер не попадает.

## Продукты Яндекса и их статус в Sky (сверять с кабинетом разработчика — условия и тарифы меняются)
| Продукт | Для чего | В Sky |
|---|---|---|
| Static API | картинка карты с метками и линией | подключён (серверный запрос) |
| HTTP Геокодер | адрес ↔ координаты | подключён |
| JavaScript API v3 | живая карта (перетаскивание, слои) | **не подключён**: нужен публичный ключ и `script-src https://api-maps.yandex.ru` в CSP — решение владельца, ослабляет политику всей страницы |
| Search API (организации) | поиск мест | не подключён: отдельный коммерческий ключ |
| Routing API | маршруты авто/пешком/транзит/грузовик, матрицы | не подключён: отдельный платный продукт по договору; формат ответа не проверялся, адаптер не писали |
| MapKit (мобильный SDK) | карта в приложениях | не подключён (нужна нативная сборка и ключ) |

Маршруты сейчас строит только Google Directions. Покрытие пешеходных и велосипедных маршрутов Google в России ограничено.

## Сделано (этап 1)
- Sky Maps Core: учёт обращений (`mapsusage.mjs`), переключатели функций и суточные пределы «поставщик:функция», журнал ошибок, проверка ключей живым запросом, таблица возможностей Sky Routing (`skymaps.mjs`).
- Вкладка «Карты» в админке (право `maps`), миграция `230_sky_maps.sql`.

## Не сделано / нужны решения
Интерактивная карта Яндекса (CSP и ключ), Search API, Routing API (договор), карта друзей, Sky Safety — см. итоговый отчёт сессии.
