# План: Sky Smart Speaker, удаление аккаунта, сериалы, лимиты, Prime, верификация, плеер/Car, маркировка, промокоды, журналы

## Аудит (что уже есть, на что опираемся)
| Область | Есть сейчас | Решение |
|---|---|---|
| Голос / Sky AI | `src/ai/voiceCommands.ts` (закрытый список команд), `src/island/aiSession.ts` + `wake.ts` («Привет, Скай»), `speech.ts` | Расширяем: команды музыки + серверный поиск. Нового движка не создаём |
| Музыка | `music_tracks` (+лицензия), `music_artists` (артист = профиль), плейлисты, избранное, `playMusicQueue`, `PlayerEngine` | Серверный нечёткий поиск `voice-resolve`; тот же плеер |
| Bluetooth | ничего | Системная маршрутизация звука ОС; в приложении — раздел настроек, статус выхода звука, честные ограничения |
| Удаление аккаунта | нет (есть заморозка, сброс 2FA) | Новое: состояние `pending_deletion` на Sky ID, 30 дней, снимок + экспорт |
| Кино | `film_movies/saved/progress/ratings` (без сериалов) | Добавить `film_series/seasons`, эпизод = фильм с `series_id/season_id/ep_no` |
| Лимиты | `storagequota.mjs` (квота байт на человека) | Настройки раздельно: личная загрузка / публикация, правятся в админке |
| Prime | `hasPrime` (сервер), `PrimeGate` (клиент) | Единый `entitlements(profile)`; сообщение «Оформите подписку с телефона» + QR на ТВ/консоли/авто |
| Верификация | `verified` только у ботов/курьеров | Новая таблица заявок и отметок, админка, история решений |
| Плеер ТВ/Car/Console | `TVFullPlayer`, `CarFullPlayer`, `MobileFullPlayer`, `fullNowStore` | Общий видеоплеер-оболочка с профилями управления; Car — без видео в движении |
| Метки музыки/книг | лицензия трека; Explicit нет | Поля explicit/legacy/источник, правка модератором с основанием |
| Карточки музыкантов | `music_artists` (только для профилей-артистов) | Артист-сущность без профиля, сопоставление, объединение, подтверждение |
| Промокоды | Sky Codes (`skycodes.mjs`): серия, HMAC-хеш, лимиты, награды | Расширяем Sky Codes (кампания, лимит на человека, тарифы), НЕ создаём вторую систему |
| Журналы | `admin_log` (цепочка хешей), `storage_events`, `ai_events` | Единая таблица событий `sky_events` + запись из ключевых мест + админ-раздел |

## Порядок и границы честности
1. Smart Speaker → 2. Удаление Sky ID → 3. Сериалы + раздельные лимиты → 4. Единый Prime → 5. Верификация → 6. Плеер/Car → 7. Метки и карточки музыкантов → 8. Промокоды → 9. Журналы → 10. Интеграционная проверка.
Каждый модуль: серверная логика и права → клиент → тест → коммит. Чего нельзя проверить здесь (Android/iOS Bluetooth, настоящая колонка, автомобиль, ТВ) — реализуется безопасный вариант, ограничение записывается явно.
