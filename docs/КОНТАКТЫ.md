## Как связаться

**Чат поддержки** — Настройки → Тех. поддержка. Это основной способ:
обращение попадает к людям, которые разбирают их, и ответ приходит туда
же.

**Почта поддержки** — `skymessenger.tp@gmail.com`. Работает и тогда,
когда доступ к аккаунту потерян.

## Откуда приходят письма от Sky

Sky отправляет письма только с адреса:

```
no-reply@skymessenger.online
```

Письмо с любого другого адреса, даже похожего, отправлено не нами.

На этот адрес не нужно отвечать — он только для отправки. Для ответа
есть чат поддержки и почта поддержки выше.

**Sky никогда не спрашивает пароль или код подтверждения** — ни в
письме, ни в чате, ни по телефону. Кто спрашивает — не из Sky, кем бы он
ни представлялся.
